Your Agent · instructions for a coding agent

Have your agent build the backend.

You do not have to write a Caret backend by hand. Give your coding agent one URL and it has everything it needs: the protocol, the reference implementations, the questions to ask you first, how to wire a real recognizer, and how to prove the result works before it says so.

The URL to give your agent.

https://docs.typewithcaret.com/agent/instructions.md

Plain Markdown, no HTML, stable. Paste it into any agent that can fetch a URL, or download it and drop it into the agent's context.

What to say

Something like this is enough:

Build me a self-hosted backend for the Caret iOS keyboard.
Follow https://docs.typewithcaret.com/agent/instructions.md exactly.
Ask me the setup questions in section 2 before you start.

What the instructions cover

SectionWhat the agent does
1 · What a backend is The routes, the shared lifecycle, what is mandatory and what is optional, when HTTPS is required.
2 · Ask before you build Language and runtime, where it runs and how the phone reaches it, which recognizer and model, credentials, supervision.
3 · Stand up the reference Clone the public repository, run the Go or Python reference backend, run the conformance checker against it.
4 · Configure it Flags and environment variables, the lane grammar for real speech, agent, image and cleanup providers.
5 · Loopback is not transcription Why a backend that passes the checker on loopback is still not done.
6 · Protect secrets Random credentials, no secrets on the command line or in logs, nothing of yours leaves your machine.
7 · Verify before you say it works Health, conformance with the real credential, a real dictated sentence through the app, a restart.
8 · From scratch Only on request: build against the protocol page with the reference as the executable specification.

What it is grounded in

The instructions do not restate the protocol; they point the agent at the protocol page and at the reference backends, and tell it to read the implementation whenever a rule is unclear rather than guess. Every command in them runs against the public repository as published. When the protocol or the reference changes, the instructions change with them at the same URL.

What it will not do

  • Touch Caret's own hosted dictation. That is set up inside the app and is not a developer API.
  • Declare success on the loopback fixture, or without a real sentence dictated through the app.
  • Put a credential, a provider key or a transcript into a log, a commit, or its own report.
