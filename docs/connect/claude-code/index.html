connect · claude code

Claude Code behind your keyboard.

The bridge runs one claude -p call per draft — print mode, read-only plan mode, nothing persisted — and hands the answer to Caret.

Status: tested

This preset was verified end to end against a real Claude Code install: a live draft came back through the bridge, idempotent replay included. The exact command per draft is claude -p --permission-mode plan --no-session-persistence "<prompt>" — every flag is stock, documented CLI syntax.

What you need

  • The claude CLI installed and signed in on the machine that will run the bridge (claude --version works).
  • Python 3.10+ (preinstalled on macOS and every mainstream Linux).
  • Tailscale on that machine and your iPhone, or a domain pointed at your VPS for public HTTPS.

1 · Get and configure the bridge

curl -fsSLO https://docs.typewithcaret.com/agent-bridge/caret_agent_bridge.py

export CARET_BRIDGE_BACKEND=claude-code
export CARET_BRIDGE_API_KEYS="$(python3 -c 'import secrets;print(secrets.token_urlsafe(32))')"
echo "$CARET_BRIDGE_API_KEYS"               # paste this into Caret later

python3 caret_agent_bridge.py --check
# config ok: backend=claude-code adapter=cli keys=1 host=127.0.0.1 port=8790 …

Want a specific model, or plan mode is not restrictive enough for your taste? Override the command rather than the code — substitution is argv-level, never a shell: 

# pin a fast model for drafting
export CARET_BRIDGE_COMMAND='claude -p --permission-mode plan --no-session-persistence --model haiku {prompt}'

The bridge refuses any command containing a permission-bypass flag (--dangerously-skip-permissions and friends) — that refusal is a startup error, by design.

2 · Run it and smoke-test locally

python3 caret_agent_bridge.py --port 8790 &

curl -s localhost:8790/v1/health | python3 -m json.tool
curl -s -X POST localhost:8790/v1/draft \
  -H "Authorization: Bearer $CARET_BRIDGE_API_KEYS" \
  -H 'Content-Type: application/json' \
  -d '{"client_request_id":"smoke-1",
       "input":{"type":"text","text":"tell Sam I am running ten minutes late"}}'

First draft takes a few seconds (a full model call). If it fails, the error message carries the CLI's stderr tail — run the claude -p command by hand as the same user to see the whole story.

3a · Local Mac

Keep the bridge on loopback and let Tailscale provide the private HTTPS URL: 

tailscale serve --bg 8790
# https://your-mac.your-tailnet.ts.net  ← this is the URL for Caret

Your iPhone must be on the same tailnet. Nothing is exposed publicly, and the certificate is handled for you. To keep the bridge running across logins, wrap the two exports and the python3 invocation in a LaunchAgent or just a tmux session — the bridge is a single foreground process and survives being supervised by anything.

3b · VPS or hosted box

Same bridge, same config, on the box where claude is signed in. Two transport options:

Tailnet (no open ports): exactly as on the Mac — tailscale serve --bg 8790.

Public HTTPS with Caddy:

# /etc/caddy/Caddyfile
caret.yourdomain.com {
    reverse_proxy 127.0.0.1:8790
}

Caddy fetches and renews the certificate automatically. The bridge stays bound to 127.0.0.1; only the proxy is reachable, and the bearer key is the lock. Run the bridge as a dedicated low-privilege user (useradd -m caret-bridge, sign claude in as that user) so a drafting call can never see more than that account does.

4 · Pair with Caret

  1. Caret settings → your backend URL (https://your-mac.your-tailnet.ts.net or https://caret.yourdomain.com).
  2. Paste the API key you generated.
  3. The app runs the health check and shows what it found — text-only Ask, no dictation, no Imagine, exactly what this bridge does.

Troubleshooting

SymptomFix
configuration error: 'claude' not found on PATH The bridge's user cannot see the CLI. Install it for that user, or put its location on PATH in the same environment that launches the bridge.
503 internal_error: claude-code exited 1: … Usually authentication — run claude -p "say ok" as the bridge's user; sign in if prompted.
504 draft_timeout Model slower than the 90 s budget. Pin a faster model with CARET_BRIDGE_COMMAND (above) or raise CARET_BRIDGE_TIMEOUT_S.
Health reachable, drafts 401 Key in the app ≠ CARET_BRIDGE_API_KEYS. Health's auth.valid tells you before a draft ever runs.

General transport and pairing problems are covered on the Connect overview.
