Retired · caret/v2 · caret/v3

This documentation is retired.

caret/v2 (the REST contract) and caret/v3 (the live-dictation WebSocket) are no longer supported, and the pages, runbooks, OpenAPI schema and agent prompts that described them are no longer published here. Old links land on this notice.

One hosted route kept its old prefix: /v2/dictionary, the per-account dictionary of the hosted service. It is current and documented on the hosted API page. Everything else under /v2/ and /v3/ is gone from the hosted service.

The archived material stays in the source repository, under legacy/, for operators who still run a pre-V4 backend and for the record. Do not build anything new from it.
