ARCHIVED · caret/v2 · caret/v3

The pre-V4 archive.

Everything on this page is retired. It documents caret/v2 (the REST contract) and caret/v3 (the optional live-dictation WebSocket), which the caret/v4 protocol replaced. The pages are preserved for operators who still run a pre-V4 backend and for the historical record — do not build anything new from them.

Building something?

Start at the overview, implement the caret/v4 protocol, and read the migration guide if you operate a V2/V3 backend today.

What replaced what

Pre-V4In caret/v4
POST /v2/dictate + chunked REST sessions The /dictate WebSocket route — live partials on every backend, one typed terminal result.
POST /v2/ask, POST /v2/imagine The /ask and /imagine WebSocket routes, sharing the same lifecycle.
caret/v3 live dictation (optional fast path) Promoted to the one and only transport, generalized to all three operations.
GET /v2/health GET /health with "protocol": "caret/v4".
Recovery via REST session replay Recovery via idempotent replay on a fresh connection — the client keeps the audio.

The migration guide covers running V2 and V4 side by side during a cutover; the paths do not collide.

Status of the archived code

The caret/v2 reference backend under legacy/reference-backend/ still runs and its hermetic test suite still passes in make test — archived means unsupported and frozen, not broken. No new features will land there, and it will not learn V4.
